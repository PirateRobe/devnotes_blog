# DevNotes 📝

A simple, lightweight blogging platform built with Django. It features a custom email-based authentication system (no usernames!), post management via the Django admin, and a commenting system for logged-in users.

## ✨ Features

- **Custom User Model**: Users log in with their email address instead of a username.
- **Blog Posts**: Create, edit, and delete posts via the Django Admin dashboard.
- **Slugs**: Automatic URL-friendly slug generation for post titles.
- **Comments**: Logged-in users can leave comments on posts.
- **Admin Dashboard**: Built-in Django admin for managing content and users.
- **Responsive Templates**: Clean, minimal HTML/CSS templates.

## 🛠️ Tech Stack

- **Backend**: Python 3.x, Django 5.x
- **Database**: SQLite (Development)
- **Frontend**: HTML, CSS (Django Templates)
- **Editor**: Visual Studio Code
